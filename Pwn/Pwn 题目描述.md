## Pwn 题目描述

**hart-gw**

```
智慧城市之裂解气分离装置现场，一台变送器网关带一个工程控制台（TCP 1504），运维用它登记变送器、读过程值、记诊断日志。
目标：拿下这个控制台进程，读取容器内的 /flag。
```

**io-panel**

```
楼宇供热系统现场，换热站的一块 IO 节点负责把现场测点对外提供出去（TCP 1501）。
目标：拿下这个节点进程，读取容器内的 /flag。
```

**rtu-fw**

```
某火力发电厂的远动终端（RTU）在升压站里跑了七年，运维只留下一份厂家升级固件和一次主站通信的抓包记录。
目标：让这台设备把它出厂预置的真值打印出来。
```

**kmod-io**

```
煤炭矿开采的采集节点上跑着一个寄存器窗口驱动，采集节点守护进程通过 TCP 1517 对外提供采集接口。
目标：拿到内核态能力，读出虚拟机内的 /flag。
```
