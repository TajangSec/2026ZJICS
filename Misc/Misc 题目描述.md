**工业数据流量分析之easy_modbus**

```
黑客通过外网进入一家工厂的控制网络，之后对工控网络中的操作员站系统进行了攻击，最终通过工控协议破坏了正常的业务。我们得到了操作员站在攻击前后的网络流量数据包，我们需要分析流量中的蛛丝马迹，找到FLAG,flag形式为 flag{}
```


**数据审计之多条件复合检测**

```
多条件复合检测
题目描述：检测同时满足以下条件的账号数量：
1.创建于2023年第一季度（1-3月）
2.最后使用日期在2024年
3.当前状态为Active且已超期（当前日期2024-06-15）提交结果的SHA256哈希值
提交形式：直接提交 SHA256 值（64 位小写十六进制），不含 flag{} 外壳
```
